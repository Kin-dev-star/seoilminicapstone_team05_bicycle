## 수정하지 않은 범위
- 카카오 자전거 경로 API 함수(`KakaoRouteRepository.java`)의 기본 요청·파싱 알고리즘
- 기존 Compose UI 컴포넌트 스타일, 리소스, 지도 렌더링 SDK 버전
- 팀 서버/DB 프로젝트, GitHub 코드, 새로운 카카오 로그인 패키지

## 반드시 유의
- **Android Gradle 전체 빌드/실제 에뮬레이터 실행은 아직 못했음**. 코드 연결은 정적 점검만 수행.
- `TEAM_HAZARD_API_URL` 값이 없거나 서버 조회에 실패하면 오프라인 데이터 사용.
- GPS 근접 경고는 과거 사고 위치 기반 **시연용**. 진짜 위험 판별 API/실시간 사고 알림 아님.
- ZIP 안 `docs/학교제출_초안/`의 PDF는 **실제 실행 캡처가 없는 준비용**. 실제 결과 채운 뒤 제출.

## 12/2 최종 보완

- `MainScreen.kt`: 실제 조회와 대응하지 않는 v4 옵션 「평지 위주」 미표시, 기능명 「자전거도로 우선」으로 정리.
- `docs/05_새UI_카카오로그인_통합대기.md`: UI v4 소스와 GitHub의 11/4 기반 로그인 패치 직접 비교 결과 기록.
