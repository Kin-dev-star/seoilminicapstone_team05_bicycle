## UI v4 반영 완료 (단, 학교 실기기 검증 전)
- `MainScreen.kt`, `Soft.kt`, `BikeApp.kt`, `BikeLoadingScreen.kt`, `bike_colors.xml`는 v4 소스 기반
- `BikeUiBridge.kt`를 통해 **실제 카카오맵 + Java 경로 검색 + 사고 마커 + GPS/TTS** 콜백 연결
- v4의 원통형 메뉴/마이페이지/설정/상하 드래그 경로창은 유지
- 기능과 혼동되지 않도록 경로 옵션은 **자전거도로 우선 / 최단 경로 2개만 활성화**. v4의 '평지 위주'는 직접 대응 API가 정해지지 않아 노출하지 않음
- 계정 화면에 12/9 계정 API 연결 전 표시
- 로딩 화면 애니메이션 완료 콜백이 지연돼도 메인 화면으로 이동하는 대체 경로 추가

## GitHub 카카오 로그인 패키지 검토 결과
- `KakaoLoginManager.java`: `UserApiClient` 토큰 획득, 정보 조회, 로그아웃을 실행하는 Java SDK 코드
- `LoginTestActivity.java` + XML: 독립적인 인증 시연 화면
- `kakao_login.patch`: 11/4 Java/XML 기반 프로젝트 전제의 전체 패치. **현재 통합본에 `git apply` 직접 실행 금지**
- README에 **실제 기기·에뮬레이터 빌드 미검증**이라고 명시되어 있음
- REST/네이티브 앱 키·키 해시·OAuth 리다이렉트 스킴과 카카오 로그인 활성화 등 관리자 설정 필요
- 카카오 사용자 ID만 서버에 전송하는 것으로는 **서버 사용자 인증이 되지 않음**. 백엔드는 카카오 토큰을 검증하고 팀 서비스 세션을 발급하도록 협의
