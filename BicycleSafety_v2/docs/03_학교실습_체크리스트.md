# 학교 실습실 테스트: 한 단계씩

## 환경 확인 (학교 PC는 매번 초기화 가능)
- [ ] Android Studio 설치 및 `C:\BS` 같은 짧은 영문 경로 사용
- [ ] SDK 37, 필요한 Emulator/Platform Tools 설치 확인
- [ ] Android Studio `File > Open`에서 `settings.gradle.kts`가 있는 폴더 열기
- [ ] `local.properties`의 `sdk.dir` 및 `KAKAO_NATIVE_APP_KEY`, `KAKAO_REST_API_KEY` 설정
- [ ] Gradle Sync → Build Output 첫 오류 없는지 확인

## 기능 테스트 (캡처 남기기)
- [ ] 앱 실행/안전 팝업 확인 → 메인 카카오맵
- [ ] 사고 마커 누르기 → **과거 사고 데이터** 지점명·건수·출처 표시
- [ ] Logcat `BicycleSafety`: `사고 자료: 오프라인 공공데이터 / 2079건`
- [ ] 경로 설정 열기 → 빈 입력시 안내 / 같은 장소 입력 안내
- [ ] 서울역 → 상계역 / 안전 우회 → 카카오 경로선 표시 및 거리·시간
- [ ] 경로 주변 150m **사고다발지역 건수** 정보 표시, 실제 회피와 구분
- [ ] 경로 옵션 '최단 경로' 선택 시 새 경로로 교체
- [ ] 현재 위치 버튼 → 권한 허용/거부 각각 테스트
- [ ] 에뮬레이터 위치를 서울 시내로 설정 → 파란 현재 위치 마커 확인
- [ ] 과거 사고다발지역 부근 모의 GPS 위치 → 접근 텍스트 + 한국어 TTS 테스트
- [ ] 경로 결과 후 '안내 시작' 버튼 → 첫 경로 안내 문구 테스트
- [ ] 오류 상황(네트워크 끊기, API 키 누락, 권한 거부)을 캡처 및 기록
- [ ] 계정 화면에는 '12/9 계정 API 연결 전' 안내 (로그인 실구현 아님)

## 분류별 결과 표 작성

| 테스트 | 정상/실패 | 화면 캡처 또는 로그 | 담당 |
|---|---|---|---|
| 화면·지도 |  |  | UI 담당 |
| 경로 요청/응답 |  |  | UI 담당 |
| 사고 데이터 |  |  | UI + 백엔드 |
| GPS 권한/위치 |  |  | GPS 공동 담당 |
| 위험 경고 TTS |  |  | TTS 공동 담당 |

`System UI isn't responding` / `Component activation exception`은 **에뮬레이터·그래픽·카카오맵 ANR**과 구분하여 Logcat `FATAL EXCEPTION`, `ANR`, `BicycleSafety`를 함께 확인하세요.
