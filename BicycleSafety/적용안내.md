# BicycleSafety 바텀시트 디자인 적용본

이 폴더가 앞으로 사용할 **단일 작업본**입니다. 원본 `BicycleSafety(1).zip`은 별도 백업으로 보관하세요. 같은 이름의 두 프로젝트를 Android Studio에 동시에 열어 섞어 수정하지 마세요.

- Figma ZIP의 `activity_route_setting_bottom_sheet.xml`을 `activity_main.xml`에 적용했습니다.
- `app/build.gradle.kts`에 중복되어 있던 `dependencies` 블록을 하나로 합쳤습니다. 카카오맵 SDK `2.15.2` 의존성은 유지합니다.
- 디자인의 drawable, colors, include XML을 추가했습니다.
- 기존 카카오맵 SDK와 안전경고 팝업 코드를 유지했습니다. 팝업 확인 후 지도 객체를 `map_container`에 추가하고 시작합니다.
- 상단 경로 설정 버튼으로 아래쪽 패널을 열고, 패널의 닫기 버튼으로 접을 수 있습니다.
- 출발지/도착지 입력과 필수값 검사는 연결했습니다.
- 원본 프로젝트에는 실제 경로 탐색 API가 없어 `경로 분석`, 지도 확대/축소, 위치, 음성 안내는 연결 전임을 안내합니다. 디자인에 포함된 예시 거리/시간 결과는 숨겼습니다.
- 카카오맵은 공식 ARM ABI를 사용하는 실행 환경이 필요합니다. 이전 x86_64 에뮬레이터에서는 여전히 실행 문제가 있을 수 있습니다.

## 적용 방법

Android Studio에서 이 폴더를 프로젝트로 열고 `Sync Project with Gradle Files`를 실행한 뒤 `app`을 실행하세요. 정상 실행 여부는 사용자의 Windows Android Studio에서 확인해야 합니다.

## 제한 사항

이 ZIP은 실제로 업로드된 BicycleSafety 프로젝트에 디자인을 적용한 것입니다. 이전 화면에 보인 Leaflet/OpenStreetMap 경로 앱의 원본 코드는 포함돼 있지 않아 Leaflet 기반 검색·경로 기능은 이 결과물에 없습니다.

빌드 검증은 이 실행 환경에서 Gradle 플러그인 `org.gradle.toolchains.foojay-resolver-convention:1.0.0`을 해결하지 못해 완료되지 않았습니다.

## 카카오 앱 키 설정 (필수)

카카오 네이티브 앱 키는 보안을 위해 git에 올리지 않습니다. 프로젝트를 받은 뒤 `BicycleSafety/local.properties` 파일 맨 아래에 다음 한 줄을 추가하고 `Sync Project with Gradle Files`를 실행하세요. 키는 팀 채널에서 따로 공유합니다.

```
KAKAO_NATIVE_APP_KEY=발급받은_네이티브_앱_키
```

코드에서는 `BuildConfig.KAKAO_NATIVE_APP_KEY`로, AndroidManifest.xml에서는 `${KAKAO_NATIVE_APP_KEY}`로 사용합니다 (예: 카카오 로그인 scheme `kakao${KAKAO_NATIVE_APP_KEY}`).
